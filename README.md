# 🎬 Movie Search
Поиск фильмов

Приложение для поиска и подбора фильмов с помощью текстовых запросов.  
Поддерживает как точный поиск по названию, так и подбор по настроению и жанру.

---

##  Возможности

🔍**Точный поиск**  найти фильм по названию, узнать режиссёра, актёров, описание
🎭 **Подбор по настроению**  «хочу что-то грустное», «фильм как Интерстеллар»
🛡️ **Устойчивость к ошибкам**  корректная обработка пустых и некорректных запросов

---

## 🚀 Запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ВАШ_ЮЗЕРНЕЙМ/movie-search.git
cd movie-search
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить приложение

```bash
python main.py
```

---

## 🧪 Тесты

```bash
pytest
```

Тесты находятся в папке `tests/` и покрывают:
точные запросы по фильмам
подбор по вайбу/настроению
граничные случаи (пустая строка, спецсимволы, SQL-инъекции)
регрессионные сценарии
